# وضعیت امکانات Donino

وضعیت زیر مربوط به نسخهٔ ۰.۱.۰ است. «برنامه» به معنای پیاده‌سازی یا تضمین زمان تحویل نیست.

| حوزه | موجود و آزموده‌شده | برنامهٔ توسعه |
|---|---|---|
| کاربر | ساخت/ویرایش/حذف، فعال/غیرفعال، حجم، انقضا، صفر کردن مصرف، تعویض شناسهٔ اتصال | شروع اعتبار با اولین مصرف، تمدید دوره‌ای، عملیات گروهی، مالکیت کاربر برای نمایندگان |
| اتصال | VLESS/REALITY، VMess/WS/TLS، Trojan/TLS، چند کاربر روی inbound | Shadowsocks، XHTTP، gRPC، fallback، ویرایش inbound بدون حذف |
| هسته | Xray، بررسی تنظیمات پیش از اجرا | به‌روزرسانی زنده با gRPC، بازگشت به آخرین تنظیمات در خطای startup، adapter sing-box |
| نود | ثبت/حذف، کلید یک‌بارنمایش و چرخش کلید، دریافت تنظیمات، heartbeat | mTLS، گروه نود، تخصیص انتخابی کاربران، چرخش نسخه و rollout مرحله‌ای |
| آمار | ترافیک واقعی، جلوگیری از حساب مجدد گزارش تکراری، نمای مصرف کاربران | ذخیرهٔ پایدار آخرین گزارش روی نود، نمودار زمانی، Prometheus و هشدار |
| اشتراک | raw، base64، ساختار Clash/Mihomo، تعویض لینک | QR محلی، صفحهٔ کاربر، خروجی اختصاصی sing-box و تطبیق User-Agent |
| مدیریت | مالک/مدیر کاربران/مشاهده‌گر، CLI، ثبت رویداد، پشتیبان SQLite | 2FA، OIDC، نمایندگی با بودجه/سقف، کلید API محدود و مدیریت نشست‌ها |
| محدودسازی | غیرفعال‌سازی، سهمیه و انقضا با اعمال دوره‌ای | محدودیت IP/HWID، سیاست سوءمصرف، کنترل پهنای باند |
| زیرساخت | نمونهٔ systemd و Nginx، cookie امن، HTTPS در پراکسی | نصب‌کنندهٔ تعاملی، Docker، ACME و تمدید گواهی، PostgreSQL، migration نسخه‌دار |
| پروتکل‌های دیگر | موجود نیست | WireGuard، AmneziaWG، Hysteria2 و TUIC با عامل و مدل دادهٔ مناسب |
| تجارت/یکپارچه‌سازی | موجود نیست | پلن و تمدید، پرداخت و کیف پول، وب‌هوک، تلگرام، واردسازی از پنل‌ها |

اولویت پیشنهادی بعدی: پایدارسازی گزارش مصرف و به‌روزرسانی زندهٔ Xray؛ سپس صفحهٔ کاربر، QR، 2FA و مهاجرت از پنل منتخب. افزودن ده‌ها پروتکل پیش از پایدار شدن چرخهٔ کاربر و نود، هزینهٔ پشتیبانی را زیاد می‌کند.

# وضعیت امکانات Donino

وضعیت پیش‌نمایش فعلی ۱.۰ alpha 13 در [گزارش پیاده‌سازی](IMPLEMENTATION-STATUS.fa.md) ثبت شده است. جدول زیر سابقهٔ انتشار پایدار ۰.۲ را نشان می‌دهد.

وضعیت زیر مربوط به نسخهٔ ۰.۲.۰ است. «برنامه» به معنای پیاده‌سازی یا تضمین زمان تحویل نیست.

مرجع اجرای توسعهٔ ۱.۰: [برنامهٔ جامع ۱۵ فازی](MASTER-PLAN.fa.md)، [ماتریس تطبیق امکانات](FEATURE-PARITY.fa.md) و [ماتریس پروتکل‌ها](PROTOCOL-MATRIX.fa.md). این صفحه خلاصهٔ وضعیت نسخهٔ فعلی است؛ اسناد جدید جای آن را با ادعای پشتیبانی آینده عوض نمی‌کنند.

| حوزه | موجود و آزموده‌شده | برنامهٔ توسعه |
|---|---|---|
| کاربر | ساخت/ویرایش/حذف، فعال/غیرفعال، حجم، انقضا، صفر کردن مصرف، تعویض شناسهٔ اتصال، دستگاه‌های چندگانه با کلید مستقل (نسخهٔ ۰.۳ در توسعه) | شروع اعتبار با اولین مصرف، تمدید دوره‌ای، عملیات گروهی، مالکیت کاربر برای نمایندگان |
| اتصال | VLESS/REALITY، VMess/WS/TLS، Trojan/TLS، چند کاربر، ویرایش، فعال/غیرفعال، حفظ کلید REALITY | Shadowsocks، XHTTP، gRPC، fallback |
| هسته | Xray، اعتبارسنجی، افزودن زندهٔ کاربر با HandlerService، rollback تنظیمات در خطای startup | ابطال هدفمند نشست بدون restart کل هسته، adapter sing-box |
| نود | ثبت/حذف، چرخش کلید، heartbeat، نسخهٔ عامل، وضعیت هسته و روش اعمال، قفل اجرای عامل | mTLS، گروه نود، تخصیص انتخابی کاربران، rollout مرحله‌ای |
| آمار | ترافیک واقعی تفکیک‌شده، جلوگیری از تکرار، صف پایدار روی نود و بازپخش پس از restart | نمودار زمانی، Prometheus، هشدار و retention |
| اشتراک | raw، base64، Clash/Mihomo، تعویض لینک، QR محلی، صفحهٔ خصوصی کاربر و QR هر اتصال | خروجی اختصاصی sing-box و تطبیق User-Agent |
| مدیریت | مالک/مدیر کاربران/مشاهده‌گر، CLI، ثبت رویداد، پشتیبان SQLite، TOTP با کد بازیابی، توکن API محدود، فهرست و ابطال نشست، مدیریت مدیران از API (۰.۳ در توسعه) | OIDC، نمایندگی با بودجه/سقف |
| محدودسازی | غیرفعال‌سازی، سهمیه و انقضا با اعمال دوره‌ای | محدودیت IP/HWID، سیاست سوءمصرف، کنترل پهنای باند |
| زیرساخت | systemd و Nginx، cookie امن، HTTPS در پراکسی، migration نسخه‌دار، پشتیبان با manifest، doctor و بازیابی تأییدشده (۰.۳ در توسعه) | نصب‌کنندهٔ تعاملی، Docker، ACME و تمدید گواهی، PostgreSQL |
| پروتکل‌های دیگر | پیش‌نمایش WireGuard و OpenVPN UDP/TCP با کلاینت واقعی؛ نصب نود دستی | AmneziaWG، Hysteria2، TUIC و موتورهای باقی با عامل و مدل دادهٔ مناسب |
| تجارت/یکپارچه‌سازی | موجود نیست | پلن و تمدید، پرداخت و کیف پول، وب‌هوک، تلگرام، واردسازی از پنل‌ها |

ترتیب توسعه طبق برنامهٔ جامع: داده/امنیت و نصب، قرارداد نود و سهمیه، DNS گیمینگ، WireGuard/OpenVPN، گسترش موتور و مسیر، سپس مدیریت تکمیلی و پایدارسازی. 2FA و مدل تخصیص نود جزو زیرساخت ابتدای این مسیرند. ابطال زندهٔ حساب بدون تضمین قطع نشست‌های قبلی، کامل محسوب نمی‌شود؛ نسخهٔ فعلی برای این عملیات عمداً از restart استفاده می‌کند.
